## Common traps to watch

- Confusing worst-case complexity with a tight bound
- Adding complexities of nested loops instead of multiplying them
- Forgetting that dynamic-array append is amortized `O(1)`
- Losing the next node before changing a linked-list pointer
- Confusing stack LIFO with queue FIFO
- Moving the wrong circular-queue index
- Forgetting the complete-tree requirement for a heap
- Replacing a two-child BST node without deleting its successor/predecessor copy
- Performing the wrong AVL rotation for a zig-zag case
- Treating Red-Black Tree deletion like insertion and checking the uncle instead of the sibling
