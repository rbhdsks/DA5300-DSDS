BST LAB EXAMINATION
===================

Student submits: rollnumber.py
Run: python rollnumber.py test.txt

Commands:
I x   insert x
D x   delete x
H     height (edges; empty=-1)
N     number of nodes
IN    inorder
PRE   preorder
POST  postorder

Duplicate insertion is ignored. Deleting a missing key does nothing.

Student public check:
1. Copy completed program to bst.py
2. Run: python public_evaluate.py
3. Public score is out of 5 (one mark per public test).

Examiner:
Put submissions in one folder, e.g. submissions/24CS1001.py.
Run: python evaluate.py submissions
Private score is out of 10; total is out of 15.

A test earns its 1 mark only when all query outputs in that test match.
The evaluator normalizes whitespace and allows a 3-second timeout per test.
